# 🕷️ Kartikey Mishra — Data & AI | Spider-Verse Portfolio

A high-performance, comic-themed personal portfolio for **Kartikey Mishra** — B.Tech CSE (AI) student in Lucknow, UP, specializing in Data Analytics, Ensemble Machine Learning, and GenAI.

![Spider-Man Theme Banner](spider_signal_mask.png)

---

## 🌟 Key Features

- 🏮 **Spider-Signal Projection Overlay**: Triggerable sky projection beam with authentic Spider-Man emblem.
- 🕷️ **Multiverse Suit Theme Switcher**: 4 interactive themes (**Classic Red/Blue**, **Miles Morales Neon**, **Spider-Man 2099**, **Iron Spider Gold**).
- 🎵 **Spider-Man 2099 Audio Theme**: Plays custom MP3 audio (`audio/spider_2099_theme.mp3`) on 2099 suit activation.
- ⚡ **Recruiter 30-Sec Executive Pitch**: Instant modal summary of key skills, projects, and credentials.
- 📊 **Spider-Web Skills Radar**: Dynamic HTML5 Canvas radar chart visualizing core competence across Python, SQL, ML, EDA, and Data Viz.
- 📩 **Real-Time Telegram Bot Alerts**: Instant alerts sent to personal Telegram bot with visitor geolocation (City, Country, ISP) and device telemetry via Vercel Serverless Function (`/api/telegram`).
- ♿ **WCAG 2.1 Accessibility & Security Hardened**: ARIA roles, skip-navigation link, CSP headers, HSTS, rate-limiting, and input sanitization.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design Tokens), Web Audio API Synth, Canvas API
- **Backend API**: Vercel Serverless Function (Node.js)
- **Integrations**: Telegram Bot API, `ipwho.is` / `ipapi.co` Geolocation API
- **Deployment**: Vercel
